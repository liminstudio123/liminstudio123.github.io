### 四、如何获取 Tello eSIM
1. **注册 Tello 账户**：
   通过我的注册链接：[Tello 注册页面](https://tello.com/account/register?_referral=P3JR3Z5B)，填写信息完成注册。我的推荐代码：P3JR3Z5B（送10美元）
   可以使用 Google 账户注册，建议姓名与支付卡一致。

2. **选择合适的套餐并填写地址**：
   选择免税州地址：[免税州地址](https://www.meiguodizhi.com/usa-address/oregon)。

3. **选择 eSIM 套餐**：
   选择3美元的 eSIM 套餐，填写 IMEI（可用 [IMEI 生成器](https://www.imei.info/zh/apple_imei_generator/)）。

4. **支付**：
   账单地址与支付卡一致，并选择中国免税地区。

5. **激活 Wi-Fi Calling**：
   订单成功后，进入 My Tello → My Settings → Wi-Fi Calling → Emergency E911 Address，填写美国地址（可通过 Google Maps 查找）。

6. **使用 eSTK 写入 eSIM**：
   如果没有 eSTK，可以在 [eSTK 官方网站](https://www.estk.me/product/estkme-eco?aid=1897) 购买，使用折扣码：1688。
   eSTK可以让国产手机秒变eSIM手机，支持苹果手机，安卓手机自主写卡，[eSTK详细介绍](https://youtu.be/SZodWGhcU2Q?si=WYRFrZ8hGOEDFYMj) 
7. **设置完成后开始使用**：
   启用 Wi-Fi Calling 时，确保已填写 E911 地址。  
   - **苹果手机**：开启 Wi-Fi Calling 时，使用翻墙工具。  
     设置 → 蜂窝网络 → Tello → Wi-Fi 通话 → 开启 Wi-Fi 通话  
   - **安卓手机（以小米为例）**：  
     设置 → 双卡与移动网络 → 选中 Tello → 启用 WLAN 通话。

### 五、注意事项

1. **10美元赠金的使用**：
   赠送的10美元仅能在取消套餐后手动选择使用，自动续费会从卡上扣费，建议手动续费，未用完的流量可转到下个月。

2. **设备更换与 eSIM 迁移**：
   更换手机时需申请新的 eSIM 卡，详情请访问 [My Tello 账户](https://tello.com/account/my_sim)。

3. **号码过期与转出**：
   未续费套餐后，号码会在5天内过期。请确保在过期前采取操作，以避免丢失号码。

4. **计划更改与支付**：
   更改套餐后，新计划会立即生效，费用当天支付。未使用的服务不会结转至下个月，除非你在当前计费周期结束前手动续订套餐。

4. **使用Telloapp可以直接打电话**：
   不用插入手机卡，有网就能打电话，不能收短信，大家可以下载上Tello APP试试
