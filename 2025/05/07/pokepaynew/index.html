📝 注册与开卡流程

✅ Step 1：注册账号 + 完成 KYC

  1. 打开注册链接 或手动填写邀请码：141897
  2. 输入邮箱、验证码，设置密码完成注册
  3. 进入“我的”页面 → 点击“立即认证”
  4. 上传身份证/护照/驾照 + 进行人脸识别

📌 每个证件限开一个账户，未用邀请码可换证件重注册。

✅ Step 2：申请虚拟卡

  1. 前往「个人中心」→「优惠券」
  2. 联系我领取 5U 开卡券
  3. 返回卡片页面 → 点击「申请虚拟卡」
  4. 使用抵扣券（最终费用 $0 或 $5）
  5. 充值任意金额后激活卡片

✅ Step 3：申请实体卡

  1. 点击「申请实体卡」
  2. 填写邮寄地址
  3. 使用 18U 优惠券 → 实付 $70（原价 $88）
  4. 卡片将免费邮寄，物流状态可在 App 内查看
